# Planify — Plataforma Inteligente para la Planificación de Viajes

Proyecto académico frontend creado con HTML, CSS y JavaScript.

## Páginas
- `index.html`: inicio y destinos destacados.
- `explorar.html`: búsqueda y filtros de destinos.
- `destino.html`: detalle de un destino seleccionado.
- `clima.html`: panel demostrativo de clima.
- `favoritos.html`: destinos guardados.
- `itinerario.html`: lista de itinerarios guardados.
- `crear-itinerario.html`: formulario para crear itinerarios.

## Cómo abrirlo
1. Descarga o descomprime la carpeta.
2. Abre `index.html` en un navegador.
3. Para probarlo localmente, se recomienda usar la extensión Live Server de Visual Studio Code.

## Funcionalidades
- Navegación entre páginas.
- Diseño adaptable a computadores y móviles.
- Búsqueda y filtro de destinos.
- Favoritos guardados en LocalStorage.
- Creación y eliminación local de itinerarios.
- Página de clima con datos ilustrativos.

## Importante
El clima es demostrativo y no consulta una API en tiempo real. Las imágenes y la fuente Poppins se cargan desde servicios externos y requieren conexión a internet. Los datos guardados en LocalStorage permanecen en el navegador/dispositivo en el que se creó el itinerario.

## Publicación
Este proyecto puede publicarse gratis mediante GitHub Pages. Sube el contenido de esta carpeta al repositorio (los archivos HTML deben quedar en la raíz del repositorio) y luego activa GitHub Pages desde Settings → Pages.
